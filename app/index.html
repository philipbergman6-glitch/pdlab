What has to be true

A strict Prisoner's Dilemma needs T > R > P > S — so defection strictly dominates — and 2R > T + S, so steady cooperation beats taking turns exploiting each other.

Patience buys cooperation, but not subgame perfection

Grim Trigger is a subgame-perfect equilibrium as soon as the future is worth more than one free lunch: δ ≥ (T−R)/(T−P). TFT is a Nash equilibrium a bit later, because a deviator can also alternate D, C, D, C forever against it.

TFT is essentially never subgame perfect: on path it needs δ ≥ (T−R)/(R−S), but after being cheated it must prefer punishing, which needs δ ≤ (T−R)/(R−S), and after mutual defection it needs δ ≤ (P−S)/(T−P). At Axelrod payoffs those cannot hold together.
