Glossary

Canonical terms for this course. Every lesson uses exactly these definitions.

Reference · grows with each lesson · Lesson 1 · Lesson 2

One-shot game (Lesson 1)

Normal-form game
A set of players, an action set for each, and a payoff function ui for each player mapping every action profile to a real number.
Action profile
One action per player, e.g. (C, D) = row cooperates, column defects.
Strategy
In a one-shot game, just an action. In repeated games, a full plan: an action for every possible history.
Best response
Player i's action that maximises ui given the others' actions.
Strict dominance
Action a strictly dominates b for player i if ui(a, a−i) > ui(b, a−i) for every a−i. A rational player never plays a strictly dominated action.
Nash equilibrium (NE)
An action profile in which every player's action is a best response to the others'. No unilateral profitable deviation.
Pareto dominance
Profile x Pareto-dominates y if every player is at least as well off in x and at least one is strictly better off.
Pareto efficient
Not Pareto-dominated by any other profile.
T, R, P, S
Temptation (defect on a cooperator), Reward (mutual cooperation), Punishment (mutual defection), Sucker (cooperate against a defector). A PD requires T > R > P > S and 2R > T + S. Canonical values: 5, 3, 1, 0.
Prisoner's Dilemma
The 2×2 symmetric game defined by the two inequalities above. Its unique NE (D,D) is Pareto-dominated by (C,C).

Repeated games (Lessons 2–4)

Stage game
The one-shot game played each round (here: the PD).
History ht
Sequence of action profiles in rounds 1…t−1.
Strategy (repeated game)
A map from every history to an action. Tit-for-Tat, Grim Trigger, ALLD are strategies; "cooperate" is not.
Subgame
The game beginning after any history.
Subgame-perfect equilibrium (SPE)
A strategy profile inducing a NE in every subgame, on- and off-path. Rules out non-credible threats.
Backward induction
Solve the last subgames, replace by equilibrium payoffs, step back. Yields SPE in finite games.
Unraveling theorem
Finitely repeated PD: unique SPE is all-D at every history. Needs only a unique stage NE.
Grim-until-k
Teaching strategy: cooperate until round k or opponent's first defection, then defect forever. Best response to Grim-until-m is k = m−1.
